# Prototype to throw away

Practice files for the lesson *A prototype you throw away*.
`fixture-repo/` is where the agent works. It holds `SPEC.md`, the spec for
an `import` command of the course's to-do program with one open question,
and `old-list.txt`, the file the import will read. `sample/count_forms.py`
is the course's own throwaway script for that question. Run it from
`fixture-repo/`:

```sh
python3 ../sample/count_forms.py
```

Work in a copy of this directory, and reset it by deleting the copy and
copying again.
