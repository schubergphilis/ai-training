# Prototype to throw away

Practice files for the lesson *A prototype you throw away*. `SPEC.md` is
the spec for an `import` command of the course's to-do program, with one
open question. `old-list.txt` is the file the import will read.
`sample/count_forms.py` is a throwaway script that answers the open
question. Run it from this directory:

```sh
python3 sample/count_forms.py
```

Work in a copy of this directory, and reset it by deleting the copy and
copying again.
