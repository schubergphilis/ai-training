# Plan a ticket

1. Read the ticket and every file it names.
2. Write the goal of the ticket in one sentence.
3. List the steps, one change per step, in the order you will make them.
4. Write one check per step that shows the step is done.
5. Show the plan to the user and wait for an answer before you change a
   file.
